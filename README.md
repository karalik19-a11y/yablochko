# YABLOKO INTELLIGENCE

Аналитическая desktop-платформа (Party Intelligence / Public Data Intelligence) для
Российской объединённой демократической партии «ЯБЛОКО»: территориальная аналитика,
социально-экономическая статистика, электоральные данные, общественные настроения
(только агрегаты), медиа и OSINT, партийные позиции и публичные документы, сценарное
моделирование и AI-аналитик.

**Статус:** Этапы 1–2 завершены (аудит; монорепозиторий + Party Context Engine с
Party Position Registry). Разработка ведётся поэтапно — см. `docs/ROADMAP.md`.

## Запуск (разработка)

```bash
npm install
npm run dev        # API (8787) + Vite dev-сервер (5173)
npm run build      # typecheck + production-сборка SPA
npm start          # собранный SPA + API на одном порту 8787
npm test           # Vitest
npm run lint       # ESLint
npm run ingest -- --mode fixture   # ingestion pipeline (fixture-режим)
npm run ingest -- --mode live      # live-режим (требует сети: CI/локально)
```

Требуется Node.js ≥ 22.13 (используется встроенный `node:sqlite`).
База данных и runtime-файлы — в `var/` (вне git).

## Принципы (непреложные)

1. **Evidence-first** — каждая цифра прослеживается до исходного документа.
2. **Нейтральная аналитика** — данные не подгоняются под партийную позицию;
   корреляция не выдаётся за причинность; категории знания (FACT / DATA / ANALYSIS /
   MODEL / OFFICIAL PARTY STATEMENT) не смешиваются.
3. **Приватность** — объект анализа: территории и агрегаты. Профилирование частных
   лиц по политическим признакам запрещено архитектурно.
4. **Provenance** — ни один источник не используется без метаданных и контрольной суммы.
